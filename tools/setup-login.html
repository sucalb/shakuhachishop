Tạo tài khoản quản trị

Trang này chạy hoàn toàn trong trình duyệt của bạn; không gửi mật khẩu hay token đi đâu (chỉ gọi GitHub để kiểm tra token có quyền ghi). Kết quả là một đoạn mã đã mã hoá để dán vào config.js.

  1. Tạo GitHub token: github.com → Settings → Developer settings → Fine-grained tokens → Generate new token. Chọn Only select repositories → repo web; quyền Contents: Read and write; đặt hạn 1 năm.
  2. Điền tên đăng nhập, mật khẩu (ít nhất 10 ký tự) cho khách và token vào dưới đây.
  3. Chép kết quả vào config.js (thay dòng login: null,) rồi đẩy lên GitHub.
